# Пищевая ценность: справочник

Источник — USDA FoodData Central (FDC), записи SR Legacy и Foundation, общественное достояние. Значения взяты из ответов API FDC 11.11.2026; номер записи FDC (fdcId) каждой строки сохранён в репозитории, `config/health-journal/food-reference-sources.json`.

- Все значения — на 100 г съедобной части (без костей, кожуры, косточек, рассола), если в строке не сказано иное.
- Для продукта в упаковке приоритет у этикетки: рецептуры российских производителей отличаются от американских записей FDC.
- ккал — Energy; Б — Protein; Ж — Total lipid (fat); У — Carbohydrate, by difference (клетчатка входит в У); Клетч. — Fiber, total dietary. «—» — в записи FDC значения нет.
- Сырое и готовое сильно различаются (крупы, макароны, мясо): смотреть столбец «Состояние». Значок ¹…¹¹ у названия — сопоставление приблизительное, пояснения после таблиц.

## Типовые блюда: расчёт по раскладке, не измерение

Ингредиенты — те же записи FDC, граммы нетто (очищенные продукты). Нутриенты ингредиентов суммируются без потерь при готовке: жир со сковороды считается оставшимся в блюде, коэффициенты удержания USDA не применялись. Выход = сумма масс − испарение или ужарка; их величина — оценка, указана в строке раскладки. Вода и соль — 0 ккал. Реальное блюдо может отличаться на 10–30 % в зависимости от жирности мяса и количества масла.
