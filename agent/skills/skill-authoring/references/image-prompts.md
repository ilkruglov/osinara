# Промпты для картинок (fal.ai)

Картинки рисует `generate_image` через fal.ai той моделью, которую выбрал владелец: GPT Image 2.6
Flare (около 10 секунд) или Seedream 5.5 (около 20 секунд). При `size: auto` пропорции выбирает
модель, при правке они обычно следуют исходнику. Другого провайдера нет: при сбое fal картинки нет или её судьба неизвестна
(тогда не повторяй вызов сам: картинка могла быть оплачена), а отказ фильтра исправь одной попыткой
по совету из ошибки. Не запрашивай варианты без просьбы.

Для правки передай `images` с исходником из Telegram или workspace и укажи в prompt, что изменить
и что сохранить. Можно передать до четырёх исходников; перед отправкой они уменьшаются до 1536 px
по длинной стороне; при `size: auto` пропорции результата обычно следуют исходнику, результат сохраняется
новым файлом. Перехода на обычную генерацию при отказе правки нет. Результат отправляй
отдельным вызовом `send_workspace_image`, только после успешного сохранения.

## Промпт

- Русский или английский, 40–80 слов; обе модели понимают русский без перевода.
- Порядок: объект → окружение → композиция и ракурс → свет → стиль и материалы → ограничения.
- Один главный объект. Перечисление пяти объектов даёт кашу.
- Ограничения в конце: `без текста, без водяных знаков, без логотипов, без людей` (что применимо).
- Текст на картинке: нужную надпись пиши в кавычках и требуй дословно, без другого текста.
  Модель может ошибиться в букве русской надписи (Seedream часто, GPT Image редко); длинную или
  важную подпись лучше добавлять к файлу при отправке.

## Что запрещено

- Бренды, марки, названия компаний и моделей (Porsche, iPhone, Lego): фильтр провайдера
  может отклонить запрос. Опиши объект словами: «серебристое среднемоторное спортивное купе».
- Известные люди и персонажи с именами.

## Размеры

| Задача | size |
| --- | --- |
| Открытка, аватар, карточка блюда | `1024x1024` |
| Баннер, пейзаж, обложка чата | `1536x1024` |
| Постер, обложка для телефона | `1024x1536` |
| Пусть модель решит, правка по исходнику | `auto` |

## Шаблоны

Открытка к празднику:
`Тёплая поздравительная открытка к [празднику], [один главный мотив: торт со свечами / ёлка с
огоньками / весенние тюльпаны], мягкий пастельный фон, лёгкая глубина резкости, фактура ручной
бумаги, композиция по центру с пустым местом внизу, без текста, без водяных знаков, без логотипов.`

Иллюстрация к сказке:
`Книжная иллюстрация: [персонаж по внешности, не по имени] в [месте], вечерний свет, акварель и
тушь, дружелюбное настроение, общий план, мягкие края, без текста, без водяных знаков.`

Карточка блюда:
`Фото блюда сверху: [блюдо] на деревенском деревянном столе, естественный свет из окна, малая
глубина резкости, несколько свежих ингредиентов вокруг тарелки, фотореализм, без текста, без
водяных знаков, без рук.`

## Проверка

- На картинке нет лишнего текста и логотипов; главный объект узнаваем; размер соответствует задаче.
- Повторяй вызов, только если ошибка инструмента пришла с `retryable: true` и советом в
  `correction` изменить `prompt` или `images`: исправь по совету и повтори один раз. Любую другую
  ошибку (сервис недоступен, исход неизвестен, повторный отказ) не повторяй, а сообщи пользователю.
