# Промпты для картинок (Nano Banana 2 с переходом на Qwen-Image и klein-4b)

Картинки рисует `generate_image`. Первый провайдер PlusVibe с моделью Nano Banana 2 (1024×1024,
около 20 секунд, ~2 ₽ за картинку); при отказе или сбое запрос уходит в NeuralDeep Qwen-Image-2.1
(2048×2048, около минуты) и затем в Cloudflare klein-4b (512×512). Не запрашивай варианты без просьбы.

Для правки передай `images` с исходником из Telegram или workspace и укажи в prompt, что изменить
и что сохранить. Можно передать до четырёх исходников; размер исходника сохраняется, результат
сохраняется новым файлом. Перехода на обычную генерацию при отказе правки нет. Результат отправляй
отдельным вызовом `send_workspace_image`, только после успешного сохранения.

## Промпт

- Русский или английский, 40–80 слов; Nano Banana и Qwen понимают русский без перевода.
- Порядок: объект → окружение → композиция и ракурс → свет → стиль и материалы → ограничения.
- Один главный объект. Перечисление пяти объектов даёт кашу.
- Ограничения в конце: `без текста, без водяных знаков, без логотипов, без людей` (что применимо).
- Текст на картинке: нужную надпись пиши в кавычках и требуй дословно, без другого текста.
  Nano Banana 2 рисует короткие русские надписи верно; klein-4b и Qwen ошибаются в буквах,
  поэтому для запасных провайдеров подпись лучше добавлять к файлу при отправке.

## Что запрещено

- Бренды, марки, названия компаний и моделей (Porsche, iPhone, Lego): фильтры провайдеров
  отклоняют запрос. Опиши объект словами: «серебристое среднемоторное спортивное купе».
- Известные люди и персонажи с именами.

## Размеры

| Задача | size |
| --- | --- |
| Открытка, аватар, карточка блюда | `1024x1024` |
| Баннер, пейзаж, обложка чата | `1536x1024` (Nano Banana даёт 4:3) |
| Постер, обложка для телефона | `1024x1536` (Nano Banana даёт 3:4) |

## Шаблоны

Открытка к празднику:
`Тёплая поздравительная открытка к [празднику], [один главный мотив: торт со свечами / ёлка с
огоньками / весенние тюльпаны], мягкий пастельный фон, лёгкая глубина резкости, фактура ручной
бумаги, композиция по центру с пустым местом внизу, без текста, без водяных знаков, без логотипов.`

Иллюстрация к сказке:
`Книжная иллюстрация: [персонаж по внешности, не по имени] в [месте], вечерний свет, акварель и
тушь, дружелюбное настроение, общий план, мягкие края, без текста, без водяных знаков.`

Карточка блюда:
`Фото блюда сверху: [блюдо] на деревенском деревянном столе, естественный свет из окна, малая
глубина резкости, несколько свежих ингредиентов вокруг тарелки, фотореализм, без текста, без
водяных знаков, без рук.`

## Проверка

- На картинке нет лишнего текста и логотипов; главный объект узнаваем; размер соответствует задаче.
- Если провайдер отклонил запрос, убери бренды и имена, не повторяй тот же промпт.
