Мия 1.8.47: хранилище ходов надёжнее, сводка без ссылок на файлы

- Проверка шага внутри транзакции завершения шага больше не ждёт соединение из общего пула: при перегрузке базы такой ход мог зависнуть.
- Две одновременные записи больших блоков журнала больше не могут заблокировать друг друга: блокировки берутся в одном порядке.
- Строка с повреждённым символом (одиночный суррогат UTF-16) хранится как есть, а не в общем хранилище блоков, где она становилась другой строкой с тем же хэшем.
- Удаление разговора по просьбе человека сразу удаляет и общие блоки журнала, на которые он ссылался последним; уборка блоков без ссылок идёт при каждом проходе.
- Сводка при смене контекста по 50 ходам собирается из текста ленты без ссылок на вложения.
