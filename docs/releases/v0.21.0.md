# Osinara v0.21.0

Единый каталог скиллов, управляемые права внешних групп и более устойчивая переписка.
Личные и семейные данные не становятся доступны группе при включении новых инструментов.

## Скиллы и инструменты

- Личный и семейный чат получают весь установленный каталог проверенных скиллов. Внешняя группа
  получает только список, который владелец сохранил из своего личного чата после подтверждения.
- Поиск в интернете, чтение публичных страниц, текущее время и планирование шагов доступны во всех
  разговорных режимах. Поиск использует официальный бесплатный Exa MCP без отдельного API-ключа.
  Ограничения и отказы провайдера показываются как ошибка, без выдуманных результатов и автоповторов.
- Корневой агент может делегировать задачу отдельному агенту во всех трёх типах чатов. Подагент
  наследует область доступа, но не получает сохранение памяти, генерацию изображений и повторную
  делегацию. Для поиска памяти он использует текст своей задачи, а не отсутствующее Telegram-сообщение.
- Текущее время во внешней группе определяется по общему часовому поясу группы. Личная учётная запись
  участника и его настройки больше не требуются; это работает и для другого бота, и для подагента.

## Bash и браузер во внешней группе

- Владелец может включить Bash и скилл браузера. Исполняемые скиллы автоматически добавляют необходимое
  право Bash; окно подтверждения заранее объясняет последствия. Это разрешение на произвольные
  команды внутри окружения группы, а не только на команды из выбранного скилла.
- Окружение подключает только рабочую папку и инструменты своей группы. Публичная сеть доступна
  через защищённый шлюз; Docker-хост, личные и семейные окружения, чужие группы и их аккаунты недоступны.
- Отзыв Bash удаляет зависимые скиллы из списка разрешений и останавливает процессы. Групповые файлы
  сохраняются. Команда, ожидавшая запуска до отзыва, не может исполниться в новом окружении без Bash.
- После пересоздания сетевого шлюза уже существующее окружение группы подключается к новому экземпляру
  при следующей операции, без потери файлов и пересоздания своего контейнера.
- Закреплены agent-browser 0.36.0 и Chrome for Testing 152.0.7977.82; архив Chrome проверяется по SHA256.
  Для сетевой изоляции внешних групп требуется Docker Engine 28 или новее. Неподходящая сеть вызывает
  отказ, а не ослабление защиты.
- Подтверждение изменения прав показывает также точный режим обработки сообщений. Существующая
  маршрутизация не меняется: all и addressed_only сохраняют общий контекст и отвечают по обращению,
  owner_only дополнительно ограничивает запуск владельцем.

## Устойчивость переписки и памяти

- Обычная цитата больше не превращается в ответ на ожидающее подтверждение. Продолжение такого запроса
  разрешается только после точной проверки в PostgreSQL; остальные реплики остаются сообщениями.
- Проверенные участники внешней группы, включая других ботов, могут использовать её рабочую папку без
  личной семейной учётной записи. Личные и семейные области по-прежнему требуют такую запись.
- Ожидание завершения хода ограничено сроком обработки также при открытии и закрытии потока событий.
  Уже прочитанная граница сохраняется при сбое закрытия; отсутствие границы фиксируется вместе с
  запросом новой сессии, чтобы поздний ответ не завершил следующее сообщение.
- Позднее завершение проверки памяти закрывает свой пакет после смены сессии, не изменяя новую.
  Ответ на действующий запрос человека продолжает исходный ход без создания лишнего пакета проверки.
- Разбиение длинной памяти на части больше не разрезает эмодзи между половинами UTF-16 символа.
  Такие записи корректно передаются в локальную модель индексации; текст памяти не изменяется.

## Проверка и обновление

- Полный локальный Docker-прогон: 2258 тестов успешно, 3 штатно пропущены; TypeScript и сборка Eve прошли.
- Сквозная проверка проходит 56 обращений в трёх режимах, Bash, скилл, нативного подагента,
  смену сессии после 50 ходов и продолжение после ошибки модели.
- Реальными Docker и Chromium проверены изоляция хоста и чужих контейнеров, замена шлюза,
  отказ устаревшей команды и сохранность файлов после отзыва.
- Контрольный поиск через действующий защищённый шлюз production вернул источник. Из локального
  Docker Exa отвечает 403; ограничение не обходится изменением сетевой защиты.
- Миграция 088 переводит проверку имён скиллов на единый каталог приложения и убирает сохранённый
  web_fetch из дополнительных прав, поскольку чтение публичных страниц теперь доступно по умолчанию.
  Bash существующим группам автоматически не выдаётся.
