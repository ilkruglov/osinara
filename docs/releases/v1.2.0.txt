Мия 1.2.0: задачи на сайтах через browser_task

- Новый инструмент browser_task в личном и семейном чате: запись, бронь, форма или выбор на сайте по описанию. Мия ставит цель, а страницы открывает и нажимает цикл, в котором быструю модель решений Jev (TypeSafe AI) спрашивают о каждом шаге; в контекст Мии попадает только итог, а не снимки страниц.
- Перед необратимым шагом (кнопка записи, брони, оплаты, отправки формы) цикл останавливается и возвращает сводку, собранную кодом: адрес, кнопка и все введённые значения. Мия пересказывает её человеку, и только после его согласия и подтверждения кнопкой делает ровно один такой шаг.
- Готово объявляется только со свидетельством: цитатой с финальной страницы. Без неё Мия говорит, что подтверждения на странице не видно. При низкой уверенности цикл задаёт вопрос Мие, не больше двух раз за задачу.
- Данные для форм берутся из анкеты personal/forms/profile.json, где каждое поле привязано к доменам; из семейной группы читается анкета того, кто поставил задачу. Поля карт и пароли не заполняются никогда, логины остаются в vault agent-browser.
- Виджеты записи в iframe и элементы в shadow DOM (YClients) обрабатываются: фрейм открывается по адресу, дни и слоты кликаются по тексту.
- Инструмент выдаётся только при заданном TYPESAFE_API_KEY. Во внешних группах его нет. Оплата не поддерживается.
- Миграция 109 добавляет таблицу прогонов; введённые значения в ней не хранятся. Существующие данные, модель, секреты и рабочие файлы сохраняются. Eve остаётся на версии 0.40.0.
