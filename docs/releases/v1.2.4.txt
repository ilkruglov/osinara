Мия 1.2.4: компакция длинных разговоров больше не сбрасывает кэш каждый ход

- Исправлено: при сжатии длинной истории старые результаты инструментов обрезались заново при каждой следующей компакции, вложенными пометками. Из-за этого каждая повторная компакция переписывала всю старую историю, кэш модели сбрасывался (около 76 тыс. некэшированных токенов на каждый раз), а в длинных разговорах вместо результатов инструментов оставались одни пометки. Обрезанный результат теперь не трогается повторно.
- Журнал проверок компакции называет сессию и ход, чтобы расход можно было сопоставлять точно.
- Включает всё из 1.2.3: задачи на сайтах через browser_task с подтверждением и анкетой, правки промптов.
- Существующие данные, модель, секреты и рабочие файлы сохраняются. Миграций нет сверх 111 из 1.2.3. Eve остаётся на версии 0.40.0 с локальными патчами.
