# Osinara v0.16.7

Patch-релиз приводит окна подтверждений в человеческий вид и снимает противоречия в их тексте.
Содержит изменения, смерженные после v0.16.6 без собственного номера версии.

## Содержание окна

- Google Workspace больше не печатает сырой JSON-массив аргументов: сервис, команда, флаги и
  параметры выводятся читаемыми строками, а точная команда остаётся отдельной строкой, чтобы
  подтверждение можно было сверить с тем, что выполнится.
- Инструмент без проверенного описания больше не даёт пустое подтверждение: показываются
  ограниченные скалярные поля фактического input.
- Окно агентного расписания использует общий формат вместо собственного, с явным разделением
  текущих и предлагаемых значений.
- Внутренние имена инструментов пользователю не показываются.

## Кнопки

- Кнопка отказа локализована. Прежняя проверка на `deny` была мёртвой: Eve присылает `cancel`,
  поэтому подпись оставалась английской, а после нажатия сообщение сообщало «Выбран ответ: Cancel»
  вместо решения об отмене.
- Добавлены подписи `continue`/`stop` для запроса о лимите сессии.

## Целостность текста

- Управляющие символы в отображаемых аргументах и ключах параметров экранируются. Перевод строки —
  обычное дело для тела письма — раньше дорисовывал поддельную строку выше настоящей, при этом
  выполнялась исходная команда.
- Решённое подтверждение больше не обещает исполнение рядом со строкой о том, что исполнения не
  будет. Снимается в том числе формулировка окна расписания предыдущего релиза.
- Framework-запрос о лимите сессии не получает выдуманное последствие и не печатает внутренние поля.
- Обрезка решённого промпта не разрубает суррогатную пару.

## Проверка

- Docker Compose test gate на Eve 0.32.0.
- Независимое ревью каждого изменения; найденные дыры с подделкой строк закрыты и покрыты тестами.
