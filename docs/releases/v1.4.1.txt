Мия 1.4.1: вход на сайт по коду из СМС доходит до конца

- Медленное открытие страницы (паспорт Яндекса грузился дольше 40 секунд) больше не считается сбоем браузера: Мия смотрит на страницу и продолжает, а не тратит ход на диагностику.
- Скриншот просмотра снова сохраняется в новом рабочем пространстве: каталог для снимков создаётся сам. Раньше каждый просмотр входа шёл без картинки и без описания экрана.
- Остановка перед отправкой формы стала настоящей: Bash больше не может кликать и печатать в том же браузере в обход подтверждения. Мия показывает скриншот и ждёт «да»; код из СМС и номер вводятся только через инструменты браузера, код нигде не сохраняется.
- Навык agent-browser оставлен только для чтения страниц с JavaScript через лёгкий движок; упоминание удалённого browser_task убрано.
- Убрана мёртвая настройка TYPESAFE_API_KEY.
