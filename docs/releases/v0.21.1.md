# Osinara v0.21.1

Повторная публикация проверенного кода v0.21.0 после безопасно отклонённой установки.
Первая попытка остановилась до миграции и до остановки приложения: серверу не хватило места
для обязательной резервной копии. Неиспользуемые образы старой v0.15.9 и неустановленной v0.21.0
удалены; пользовательские данные, текущая версия и предыдущая рабочая версия сохранены.

Отклонённая заявка остаётся в истории. Новая версия требует нового подтверждения владельца,
не сбрасывает старую ошибку и не отключает проверку свободного места или резервное копирование.
Прикладной код по сравнению с v0.21.0 не менялся.

## Что получает установленная v0.20.1

- Единый каталог проверенных скиллов в личных и семейных чатах. Во внешних группах остаётся
  только список, разрешённый владельцем из его личного чата.
- Веб-поиск через официальный бесплатный Exa MCP, чтение публичных страниц, текущее время,
  планирование шагов и нативная делегация во всех разговорных режимах.
- Включаемые владельцем Bash и браузер во внешней группе. У окружения только собственные файлы,
  инструменты и защищённый выход к публичным сайтам; чужие группы, личные аккаунты и Docker-хост
  недоступны. После замены сетевого шлюза существующее окружение восстанавливает подключение.
- Отзыв Bash останавливает процессы, убирает зависимые скиллы и запрещает запуск устаревшей команды,
  сохраняя групповые файлы. Подтверждение показывает точные последствия и режим сообщений.
- Время внешней группы работает без личной учётной записи участника. Подагент сохраняет область
  доступа, но не получает сохранение памяти, генерацию изображений и рекурсивную делегацию.
- Исправлены продолжение обычной переписки после цитат, ограничение ожидания завершения хода,
  поздние события проверки памяти после смены сессии и разбиение эмодзи при индексации длинной памяти.

Подробности: [описание v0.21.0](https://github.com/nyxandro/osinara/releases/tag/v0.21.0).

## Проверка и совместимость

- Исходный код прошёл 2258 локальных тестов, 3 штатно пропущены; CI v0.21.0 также прошёл полностью.
  Этот релиз заново проходит штатные Docker-тесты и сборку в CI.
- Реальными Docker и Chromium проверены изоляция, замена шлюза и отзыв прав без потери файлов.
  Контрольный Exa-запрос через production-шлюз успешен; локальный Docker-отказ 403 не обходится.
- Миграция 088 применяется один раз. Bash существующим группам автоматически не выдаётся.
- Для изолированной сети внешних групп требуется Docker Engine 28 или новее.
