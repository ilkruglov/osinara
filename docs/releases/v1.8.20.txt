Мия 1.8.20: легче память сервера, настройки под размер установки, быстрее личные ответы

- Сервер больше не держит отдельную копию набора навыков песочницы для каждого разговора: одна копия на всех. На нагрузочном стенде это убрало рост памяти, который заканчивался перезапуском.
- Рабочий журнал ходов теперь хранит повторяющиеся большие блоки (системные инструкции, историю разговора) один раз, а не в каждом ходе — примерно вдвое меньше места на ход. Старые записи читаются как прежде.
- Настройки под размер установки задаются в окружении: сколько чатов и шагов идёт одновременно, сколько тихих проверок памяти в полёте, сколько ждать серию личных сообщений, сколько живёт контейнер песочницы без дела, размер памяти сервера. Для одной семьи значения по умолчанию: контейнер живёт шесть часов без дела (команды выполняются без холодного старта), тихих проверок не больше двух — они не отбирают процессор у живого ответа.
- Ожидание продолжения серии личных сообщений стало настройкой (по умолчанию 2 с); в установке Мии задано 0,7 с — ответ приходит быстрее, несколько сообщений подряд по-прежнему собираются в один ход.
- Тихая проверка памяти, попав в уже занятый слот, сразу получает текущие записи слота и уточняет запись за один шаг, а не перечитывает память отдельным запросом.
- Сборка больше не зависит от скачивания Google Workspace CLI с GitHub: архив лежит в репозитории.
- Подготовлен образ эмбеддера с BERTA в формате ONNX — поиск по памяти на четверть быстрее; включится в следующем выпуске.
