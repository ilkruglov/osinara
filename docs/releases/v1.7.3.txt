Мия 1.7.3: правки по ревью Codex релизов 1.4–1.6

- Bash больше не может обойти подтверждения браузера комментарием, кавычками, экранированием, путём к программе, вложенным shell или второй командой в той же строке: сессия читателя должна стоять сразу после каждого вызова браузера.
- Кнопка со словом «cookies» внутри заполненной формы снова требует подтверждения; без подтверждения закрываются только настоящие баннеры вне формы.
- Лавка: запрос уходит только со страницы lavka.yandex.ru, даже если вкладку увели на другой сайт посреди вызова; добавление в корзину, заказ и отмена не повторяются при восстановлении после сбоя (одинаковое добавление в одном ходе выполняется один раз); заказ привязан к адресу и карте из предпросмотра и не уйдёт, если их поменяли; Мия не выбирает карту сама, если выбранной нет; номер созданного заказа не теряется при сбое проверки оплаты.
- Сообщения во время хода: доставка считается по номеру шага модели, поэтому повтор шага после сбоя снова показывает сообщение, а не помечает его увиденным; в конце хода увиденное фиксируется повторно, а при сбое записи сообщение скорее покажется дважды, чем потеряется; пятьдесят сообщений не для Мии больше не прячут следующее «Мия, стоп»; пачка сообщений помнит, какие из них уже были показаны; проверки авторских навыков читают результат инструмента без обёртки.
