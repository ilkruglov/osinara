Мия 1.7.0: картинки через Nano Banana 2, правка через Qwen-Image

- Новый провайдер картинок PlusVibe: генерация моделью Nano Banana 2 (около 20 секунд, 1024×1024, надписи по-русски без ошибок), правка фото той же моделью с передачей исходников напрямую, без публичных ссылок. Включается ключом PLUSVIBE_API_KEY, без него всё работает как раньше.
- NeuralDeep теперь умеет править фото: Qwen-Image-2.1 меняет картинку по описанию за несколько секунд и сохраняет её размер. Для правки он идёт сразу после PlusVibe, klein-4b остаётся запасным.
- Порядок провайдеров: генерация PlusVibe → Cloudflare klein-4b → NeuralDeep, правка PlusVibe → NeuralDeep → Cloudflare. Справочник промптов навыков обновлён под новые модели.
