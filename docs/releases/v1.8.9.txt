Мия 1.8.9: чистка кода и облачный браузер только для чтения

- Облачный браузер (Browserless), которым Мия открывает страницы за капчей, теперь только читает: открыть, прочитать, прокрутить, сделать снимок. Кликать и заполнять формы в нём нельзя, иначе он позволял отправить публичную форму с телефоном человека мимо окна подтверждения. Действия на сайтах идут только через browser_act с подтверждением.
- Подсказки модели больше не предлагают входить на сайты через auth vault и кликать через Bash: это всё равно запрещено, и Мия тратила ходы на отказы.
- Из кода убраны альтернативные модели чата (MiniMax, NeuralDeep, Groq, OpenCode Go, OpenRouter) и путь через подписку Codex: прод давно работает на DeepSeek. Groq остаётся для распознавания голоса, генерация картинок без изменений.
- Убраны мёртвый код, неиспользуемые файлы и колонка базы skill_allowlist; одинаковые куски кода (чтение ответов с лимитом размера, таймауты запросов к Telegram, обрезка текста, хэши, проверки владельца) сведены в общие функции. Обрезка текста в окнах подтверждения больше не режет эмодзи пополам.
