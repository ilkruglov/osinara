Мия 1.8.45: rich-посты читаются как обычные сообщения

- Из rich-поста канала (Bot API 10.1: блоки с текстом и файлом) поднимается не только фото, но и файл: дальше работают те же права, что у обычного сообщения. Во внешней группе картинка доступна по inspect_workspace_image, текстовый файл по import_telegram_attachment; в семейной группе и личке всё читается как раньше.
- Текст поста сохраняется при любом вложении: если файл отклонён или это голос, видео, аудио, в очередь попадает пост без медиа-блоков (подписи становятся абзацами). Метка «только текст» больше не нужна: в сохранённом апдейте нечего поднимать заново.
- Релиз 1.8.44 опубликован из промежуточного коммита и на прод не ставился; 1.8.45 заменяет его.
- README приведён к текущему состоянию: память, картинки, оценка ходов, rich-посты, конфигурация модели, изоляция песочниц.
